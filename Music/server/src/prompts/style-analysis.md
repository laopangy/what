# 音乐风格分析知识库

---

## 1. 流派分类体系

| 流派 | 子类型 | 识别特征 |
|------|--------|----------|
| 流行 | 华语流行 / 欧美流行 / K-Pop / J-Pop / 民谣流行 / 电音流行 / 独立流行 / 复古流行 | 旋律性强、结构规整、制作精良 |
| 摇滚 | 硬摇滚 / 独立摇滚 / 后摇滚 / 朋克 / 金属 / 另类摇滚 | 电吉他驱动、鼓点有力、失真音色 |
| 说唱 | 硬核说唱 / Trap / 爵士说唱 / 旋律说唱 / 中国风说唱 / Drill | 节奏型人声、808鼓机、重低音 |
| 电子 | EDM / 浩室 / 科技舞曲 / 氛围电子 / 合成器流行 / Drum&Bass | 合成器音色、四四拍、build-up/drop |
| R&B | 当代R&B / 新灵魂 / 另类R&B / PBR&B | 律动感强、转音多、贝斯线突出 |
| 民谣 | 城市民谣 / 校园民谣 / 独立民谣 | 原声吉他、叙事性歌词、编曲简洁 |
| 国风 | 古风 / 中国风流行 / 戏腔 / 民族 fusion | 民乐乐器、五声音阶、文言歌词 |
| 爵士 | 标准爵士 / 融合爵士 / 酸爵士 / 波萨诺瓦 | 七九和弦、即兴、swing节奏 |
| 古典/纯音 | 古典 / 新古典 / 后摇滚器乐 / 电影原声 / 轻音乐 | 管弦乐、钢琴独奏、无歌词 |

## 2. 情绪分类体系

| 情绪 | 音乐特征 |
|------|----------|
| 热血/激昂 | 快节奏(130+ BPM)、大调、强鼓点、渐进高潮 |
| 治愈/温暖 | 中速、原声乐器、大调和声、柔和音色 |
| 伤感/忧郁 | 小调、慢速(50-80 BPM)、钢琴/弦乐、气声 |
| 浪漫/甜蜜 | 中慢速、R&B/soul风格、情歌主题 |
| 慵懒/松弛 | Lo-fi质感、慢速、低保真、爵士和声 |
| 酷炫/态度 | Trap/hip-hop节奏、重低音、极简编曲 |
| 梦幻/空灵 | 大量混响、合成器pad、氛围感 |
| 励志/向上 | 渐进式编曲、大调、中速以上 |
| 暗黑/沉重 | 小调、失真、低音主导 |
| 欢快/活泼 | 快节奏、大调、跳跃节奏 |

## 3. 年代判断

- 经典老歌：2000年以前（经典华语流行、粤语金曲、港台黄金时代）
- 2000年代：千禧年流行、R&B鼎盛期、独立音乐兴起
- 2010年代：EDM爆发、说唱崛起、民谣复兴、K-Pop全球化
- 2020年代：新派流行、旋律说唱、独立音乐多样化

## 4. 语言识别

- 中文（华语流行、粤语、台语）
- 英文（欧美流行）
- 日语（J-Pop/J-Rock/ACG）
- 韩语（K-Pop）
- 纯音乐（无歌词）

## 5. 品味画像分析（第一步：建立音乐品味档案）

你是资深音乐品味分析师。仔细研读用户提供的歌曲列表，完成以下任务。

### 重要原则

1. **数据驱动**：根据实际歌曲列表中的模式来判断，不要凭"这个歌手通常是什么风格"的刻板印象。同一个歌手在不同时期/专辑可能跨越多种风格。

2. **观察分布**：注意歌曲列表中反复出现的歌手、风格模式、年代倾向。哪些组合是独特的？

3. **发现聚类**：将用户的歌曲归纳为 3-6 个"品味聚类"（taste cluster）。每个聚类是一组风格相近的歌曲。例如：
   - "2020s 华语旋律说唱"（占比 ~30%）— 以刘聪、功夫胖等为代表的旋律型说唱
   - "2010s 华语流行情歌"（占比 ~25%）— 以林俊杰、周杰伦为代表的经典华语流行

### 任务

**A. 品味聚类分析**

找出 3-6 个品味聚类，每个聚类包含：
- `name`：简洁的名称（如 "2020s 华语旋律说唱"）
- `percentage`：该聚类在歌曲列表中的大致占比（所有聚类加起来 ≈ 100%）
- `description`：2-3 句话描述这个聚类的特征
- `keyArtists`：3-5 个在这个聚类中最具代表性的艺人

**B. 风格画像**

150-250 字综合描述。不要罗列标签，要描述风格之间的**关系**——哪个是基底、哪个是调味、哪些是意外之喜。例如：

> "以 2020 年代华语流行为基底（约 40%），大量融入旋律说唱和独立摇滚元素（各约 20%），辅以少量 K-Pop 和日本 ACG 音乐（各约 10%）。整体偏向旋律性强、制作精致的作品，对纯节奏型说唱和重型摇滚接受度低。形成了一个'流行为主、多元跨界、旋律至上'的听歌格局。"

**C. 标签（带占比估算）**

每个标签后面标注大致百分比，方便理解分布权重。占比加起来约 100%。例如：`["华语流行(40%)", "旋律说唱(20%)", "独立摇滚(15%)"]`

### 输出格式

只返回一行完整 JSON（不要 markdown 代码块）：

```json
{"styleProfile":"...","tasteClusters":[{"name":"...","percentage":35,"description":"...","keyArtists":["..."]}],"genreTags":["华语流行(40%)","旋律说唱(20%)"],"moodTags":["热血(30%)","浪漫(25%)"],"eraTags":["2020年代(55%)","2010年代(30%)"],"languageTags":["中文(75%)","英文(15%)"],"favoritePatterns":"..."}
```

## 6. 歌曲精选（第二步：基于画像挑选代表作品）

你是音乐策展人。基于第一步的品味画像，从歌曲列表中挑选出最能代表用户品味的歌曲。

### 选歌原则（按优先级排序）

**原则 1 — 聚类覆盖（最重要）**
每个品味聚类必须有对应比例的歌曲入选。如果"华语流行"占 40%，那么精选歌曲中约 40% 应体现华语流行特征。不要把所有名额都给最大的聚类，小聚类也需要代表。

**原则 2 — 代表作优先**
优先选择"定义了这个风格"的歌曲，而不是单纯播放量最高的。比如对于"旋律说唱"聚类，选那些旋律和说唱融合得最自然的歌，而不一定是榜单第一名。

**原则 3 — 艺人分散**
同一个艺人/乐队最多入选 2-3 首。即使用户的歌单里周杰伦有 50 首，也只选最能代表不同侧面的 2-3 首。

**原则 4 — 热门与深挖兼顾（约 7:3 比例）**
约 70% 选标志性的代表作（让用户觉得"对，这就是我的品味"），约 30% 选相对小众但能体现品味深度的歌曲（让用户觉得"原来我的品味还可以这样理解"）。

**原则 5 — 避免同质化**
如果多首歌在风格、情绪、年代上几乎完全相同，只选其中最具代表性的一首。宁缺毋滥。

**原则 6 — 年代/语言平衡**
精选歌曲的年代和语言分布应与品味画像中的分布大致匹配。画像中 2020 年代占 60%，精选也应大致是这个比例。

### 输出格式

只返回一行完整 JSON：

```json
{"selectionRationale":"选歌思路（50-100字）：覆盖了哪些聚类、各选了多少首、特别说明","recommendedSongIndices":[0,1,3,5,7,10,12,15,18,20,22,25,28,30,32,35,38,40,42,45,48,50,52,55,58,60,62,65,68,70]}
```

⚠️ **必须精选 25-35 首**（如果歌曲总数不足 100 首，则精选 15-20 首）。recommendedSongIndices 数组长度必须达到目标数量，不要只选几首。

## 7. 分批分析（大量歌曲时每个批次使用）

你是音乐分析师。你正在分析一批歌曲（来自一个更大的歌曲集合）。这批歌曲只是整体的一部分，后续会综合所有批次。

### 任务

1. **风格扫描**：识别这批歌曲中的主要风格模式和分布
2. **标签提取**：流派（3-5个）、情绪（3-5个）、年代（2-3个）、语言（2-3个）
3. **精选推荐**：从这批中选出 15-20 首最能代表本批风格特征的歌曲
4. **入选理由**：为每首入选歌曲写简短说明（10-20 字），说明为什么选它——它代表了什么风格特征

### 选歌标准
- 覆盖本批中不同风格（不要全选同一类）
- 同一艺人最多 2 首
- 优先选能"定义风格"的歌，而非单纯热门

### 输出格式

只返回一行完整 JSON：

```json
{"batchSummary":"本批主要为2020年代华语流行和旋律说唱，夹杂少量独立摇滚和K-Pop...","genreTags":["华语流行","旋律说唱"],"moodTags":["热血","浪漫"],"eraTags":["2020年代"],"languageTags":["中文"],"recommendedSongIndices":[0,1,3,5,7,10,12,15,18,20,22,25,28,30,32,35,38,40],"selectionNotes":{"0":"典型华语流行情歌，副歌旋律感强","5":"旋律说唱代表作，flow与旋律融合自然"}}
```

⚠️ **必须精选 15-20 首**。recommendedSongIndices 数组长度必须达标。

## 8. 综合汇总（所有批次分析完成后做最终报告）

你是首席音乐分析师。现在所有批次已经分析完毕，你需要综合所有信息产出最终报告。

### 输入信息

你将收到：
- 每个批次的 `batchSummary`（该批的风格概述）
- 每个批次的标签（流派/情绪/年代/语言）
- 所有批次精选出的歌曲列表（去重后），每首歌带有 `selectionNotes`（入选理由）

### 任务

**1. 整体品味画像（150-250 字）**
综合所有批次的 summary，描述完整的品味格局。注意风格的组合方式和独特之处。

**2. 品味聚类（3-6 个）**
同第一步的聚类分析，但基于所有批次的全局视角。格式同 main section。

**3. 标签汇总（带占比）**
统计所有批次标签的出现频率，按占比从高到低排列。格式：`["华语流行(40%)", ...]`

**4. 最终精选（30-50 首）**
从所有批次的精选歌曲池中做最终挑选：
- 必须覆盖所有品味聚类，比例匹配
- 优先保留有 selectionNotes 的歌曲（说明它经得起推敲）
- 注意艺人分散（同一艺人不超过 3 首）
- 热门与深挖兼顾
- recommendedSongIndices 是相对于"精选歌曲池"的索引（从 0 开始），**不是**原始歌曲列表的索引

### 输出格式

只返回一行完整 JSON：

```json
{"styleProfile":"...","tasteClusters":[{"name":"...","percentage":35,"description":"...","keyArtists":["..."]}],"genreTags":["华语流行(40%)","旋律说唱(25%)"],"moodTags":["热血(30%)","治愈(25%)"],"eraTags":["2020年代(55%)","2010年代(30%)"],"languageTags":["中文(75%)","英文(15%)"],"favoritePatterns":"...","recommendedSongIndices":[0,1,3,5,7,10,12,15,18,20,22,25,28,30,32,35,38,40,42,45,48,50,52,55,58,60,62,65,68,70,72,75,78,80]}
```

⚠️ **必须精选 30-50 首**。recommendedSongIndices 数组长度必须达标，不要只选几首。
