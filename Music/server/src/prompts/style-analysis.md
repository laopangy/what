## 1. 流派分类体系

| 流派 | 子类型 | 识别特征 |
|------|--------|----------|
| 流行 | 华语流行 / 欧美流行 / K-Pop / J-Pop / 民谣流行 / 电音流行 / 独立流行 / 复古流行 | 旋律性强、结构规整(主歌-副歌)、制作精良 |
| 摇滚 | 硬摇滚 / 独立摇滚 / 后摇滚 / 朋克 / 金属 / 另类摇滚 | 电吉他驱动、鼓点有力、失真音色、BPM 120-180 |
| 说唱 | 硬核说唱 / Trap / 爵士说唱 / 旋律说唱 / 中国风说唱 / Drill | 节奏型人声、808鼓机、重低音、flow变化 |
| 电子 | 电子舞曲(EDM) / 浩室 / 科技舞曲 / 氛围电子 / 合成器流行 / Drum&Bass | 合成器音色、四四拍鼓点、build-up/drop结构 |
| R&B | 当代R&B / 新灵魂 / 另类R&B / PBR&B | 律动感强、转音多、贝斯线突出、BPM 60-100 |
| 民谣 | 城市民谣 / 校园民谣 / 独立民谣 | 原声吉他、叙事性歌词、编曲简洁 |
| 国风 | 古风 / 中国风流行 / 戏腔 / 民族 fusion | 民乐乐器(笛箫琵琶古筝)、五声音阶、文言歌词 |
| 爵士 | 标准爵士 / 融合爵士 / 酸爵士 / 波萨诺瓦 | 七九和弦、即兴、swing节奏、铜管/钢琴 |
| 古典/纯音 | 古典 / 新古典 / 后摇滚器乐 / 电影原声 / 轻音乐 | 管弦乐、钢琴独奏、无歌词、结构复杂 |

## 2. 情绪分类体系

| 情绪 | 音乐特征 |
|------|----------|
| 热血/激昂 | 快节奏(130+ BPM)、大调、强鼓点、电吉他/合成器、渐进高潮 |
| 治愈/温暖 | 中速、原声乐器、大调和声、柔和音色、歌词积极 |
| 伤感/忧郁 | 小调、慢速(50-80 BPM)、钢琴/弦乐、气声唱法 |
| 浪漫/甜蜜 | 中慢速、R&B/soul风格、柔和转音、情歌主题 |
| 慵懒/松弛 | Lo-fi音质、慢速、低保真质感、爵士和声 |
| 酷炫/态度 | Trap/hip-hop节奏、重低音、态度歌词、极简编曲 |
| 梦幻/空灵 | 大量混响、合成器pad、飘逸女声、氛围感 |
| 励志/向上 | 渐进式编曲、大调、中速以上、歌词正能量 |
| 暗黑/沉重 | 小调、失真、低音主导、不和谐和声 |
| 欢快/活泼 | 快节奏、大调、跳跃节奏、明亮音色 |

## 3. 年代判断

- **经典老歌**：2000年以前（经典华语流行、粤语金曲、港台黄金时代）
- **2000年代**：千禧年流行、R&B鼎盛期、独立音乐兴起
- **2010年代**：EDM爆发、说唱崛起、民谣复兴、K-Pop全球化
- **2020年代**：新派流行、旋律说唱、独立音乐多样化、AI音乐出现

---

## 4. 语言识别

- **中文**（华语流行、粤语、台语）— 周杰伦/林俊杰/陈奕迅/邓紫棋等
- **英文**（欧美）— Taylor Swift/The Weeknd/Ed Sheeran等
- **日语**（J-Pop/J-Rock）— 米津玄师/YOASOBI/Official髭男dism等
- **韩语**（K-Pop）— BTS/BLACKPINK/IVE等
- **纯音乐**（无歌词）— 钢琴曲/管弦乐/后摇滚/氛围音乐

---

## 5. 分析维度（单次分析）

1. **风格画像**：80-150字，综合流派+情绪+年代+语言，描述用户音乐品味画像
2. **流派标签**：选出3-8个最重要的流派标签
3. **情绪标签**：选出3-6个最主要的情绪倾向
4. **年代标签**：选出2-4个年代分布
5. **语言标签**：选出2-4个语言分布
6. **偏好特征**：用一句话描述独特模式（如"偏爱华语旋律说唱，但混入了大量独立摇滚"）
7. **精选推荐**：选出20-30首最能代表用户品味的歌曲索引号（从0开始）

⏬ 返回格式：
```json
{"styleProfile":"...","genreTags":["华语流行","旋律说唱"],"moodTags":["热血","伤感"],"eraTags":["2020年代"],"languageTags":["中文"],"favoritePatterns":"...","recommendedSongIndices":[0,5,12,20]}
```
